# sharkipediaR: Access Sharkipedia Trait and Trend Data

G'day mate! This is a tidyverse-oriented R client for publicly
accessible Sharkipedia life-history trait and population trend data.
Provides polite HTML retrieval, modular parsing, and reproducible
ecological workflows.
